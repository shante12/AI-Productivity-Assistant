# EventFlow AI

EventFlow AI — Intelligent Event Planning Platform

Build a modern, professional, responsive AI-powered Event Planning Website called EventFlow AI.

The platform should help users plan events from idea to execution using AI. It should combine event management, intelligent research, email generation, and an AI planning assistant into one polished dashboard.

1. Core Problem

Event planning can be overwhelming because users need to research venues and vendors, communicate with guests, create schedules, manage budgets, and coordinate many tasks.

EventFlow AI should solve this by providing a centralized workspace where AI helps users:

Plan an event step-by-step

Research venues, vendors, themes, catering, activities, and logistics

Generate professional event-related emails

Ask questions through an AI chatbot

Organize event information in a dashboard

Receive AI-generated recommendations while maintaining human control over important decisions

The product should feel like a combination of an event planner, research assistant, communication assistant, and project dashboard.

15. Responsible AI Disclaimer

Create a visible but non-intrusive Responsible AI section.

Display:

Responsible AI Notice

EventFlow AI provides suggestions and generated content to assist with event planning. AI-generated information may contain errors, omissions, or outdated information. Users should verify important details, prices, availability, legal requirements, safety information, and vendor credentials independently before making decisions.

EventFlow AI does not replace professional, legal, financial, safety, or other expert advice.

For research results, clearly identify:

AI-generated suggestions

User-provided information

Verified external information

Never claim that AI information is guaranteed to be accurate.

16. Prompt Engineering

Design the AI interactions using structured prompts rather than vague instructions.

Role:

Objective:
Provide practical recommendations that help the user make progress.
